## 💡 О проекте

Обычный WireGuard сегодня блокируется большинством провайдеров за считанные секунды из-за легко узнаваемой сигнатуры протокола. Для решения этой проблемы существует серверный проект **[Ground-Zerro/Phobos](https://github.com/Ground-Zerro/Phobos)**, который маскирует WireGuard-трафик под безобидные пакеты видеосвязи (STUN/WebRTC) и шифрует заголовки.

Изначально для подключения к Phobos на Windows приходилось запускать консольные утилиты-компаньоны, вручную перенастраивать порты и держать рядом открытый официальный клиент WireGuard.

**Этот клиент создан для того, чтобы всё просто работало в один клик:**
- Вы скачиваете **один маленький файл** (`phobos-client.exe` весит всего 1 МБ).
- Перетаскиваете в него файл конфигурации (`.tar.gz`), выданный сервером или ботом.
- Нажимаете кнопку **«Подключить»** — и у вас сразу работает свободный интернет.

Никаких сторонних программ, никаких сложных настроек и никаких раздражающих черных окон консоли.

## 🌟 Почему им удобно пользоваться

- 🚀 **Запускается мгновенно и не «ест» память**: Приложение написано на чистом Rust и нативном Win32 API. В отличие от современных программ на Electron или игровых движках, оно весит около 1 МБ и практически не расходует оперативную память и процессор.
- 🎯 **Всё включено (All-in-One)**: Вам **не нужно** ставить официальный WireGuard. Внутри программы уже есть собственный VPN-движок и сетевой драйвер.
- 🤫 **Бесшумная работа**: Приложение не мигает окнами командной строки при подключении, смене маршрутов или отключении — интерфейс работает гладко и чисто.
- 🖱 **Удобный Drag & Drop**: Скачали архив с профилем из панели? Просто перетащите его мышкой в окно программы.
- 📊 **Понятный интерфейс**: Внешний вид вдохновлён классическим WireGuard: список туннелей слева, статус подключения, живая статистика переданных мегабайт, текущая скорость и лог событий.

## 🚀 Как начать пользоваться

1. Скачайте свежую версию **`phobos-client.exe`** из раздела **[Релизы](https://github.com/vladimir214sd/PhobosWG_Client/releases/latest)**.
2. Запустите файл (согласитесь на запрос прав администратора — они нужны единожды для создания виртуального сетевого адаптера).

4. Нажмите **«Подключить»**.

## 🔬 Принцип работы (Техническое описание)

Под капотом приложения работает связка из пользователейского WireGuard-движка, модуля маскировки Phobos и сетевого драйвера ядра Windows:

### 1. Обработка профиля Phobos
Из панели управления Phobos скачивается архив `.tar.gz`, содержащий:
- `wg0.conf` — стандартные параметры WireGuard (приватный ключ клиента, публичный ключ сервера, IP внутри туннеля, MTU 1280).
- `wg-obfuscator.conf` — параметры маскировки: общий секретный ключ обфускации, параметры добавления мусорных байт (dummy bytes) и флаг включения режима `STUN`.

### 2. Схема прохождения трафика

```text
       [ Браузеры и программы Windows ]
                       │
                       ▼
    [ Виртуальный сетевой адаптер Wintun ]
          IP: 10.x.x.x / MTU: 1280
                       │
                       ▼
       [ Userspace BoringTun Engine ]
   Шифрование пакетов: ChaCha20-Poly1305
                       │
                       ▼
         [ Модуль обфускации Phobos ]
  Симметричный XOR с динамическим CRC8-сдвигом
                       │
                       ▼
            [ STUN Инкапсулятор ]
  Оборачивание в пакеты STUN Data Indication
  (внешне выглядит как WebRTC / звонок в Discord)
                       │
                       ▼
       [ Физический сокет Windows (UDP) ]
  Привязан к физическому шлюзу по IP_UNICAST_IF
                       │
                       ▼
       [ Провайдер / DPI (Блокировки нет) ]
                       │
                       ▼
               [ Сервер Phobos ]
```

### 3. Механизм обфускации и STUN-маскировки
- **XOR / CRC8 обфускация**: Заголовки WireGuard (типы сообщений 0x01, 0x02, 0x04) легко детектируются DPI. Модуль обфускации накладывает на зашифрованный пакет обратимую побитовую маску, рассчитываемую через полиномиальную таблицу CRC8 от ключевой последовательности. В результате трафик теряет любые статистические и энтропийные маркеры WireGuard.
- **STUN-инкапсуляция**: Пакет оборачивается в стандартный контейнер протокола STUN (RFC 5389) с заголовком `0x0115` (Data Indication) и Magic Cookie `0x2112A442`. Любая система анализа трафика (DPI) классифицирует такой поток как обычный голосовой или видеозвонок, не подлежащий фильтрации.

### 4. Архитектура Zero-Process (без дочерних процессов)
Большинство VPN-клиентов вызывают системные утилиты `route.exe` и `netsh.exe` через командную строку. В Windows 11 это вызывает кратковременное открытие окон терминала.
В данном клиенте **дочерние процессы исключены полностью**:
- **Установка IP и маски**: через Win32 API `CreateUnicastIpAddressEntry` (`iphlpapi.dll`).
- **Установка MTU**: через Win32 API `SetIpInterfaceEntry` (`iphlpapi.dll`).
- **Таблица маршрутизации (0.0.0.0/1, 128.0.0.0/1)**: через `CreateIpForwardEntry2` и `DeleteIpForwardEntry2` (`iphlpapi.dll`).
- **Настройка DNS**: через вызов `SetInterfaceDnsSettings` (`iphlpapi.dll`).

Все сетевые манипуляции выполняются напрямую в памяти ядра Windows за доли миллисекунды.

## 🛠 Сборка из исходников

Если вы хотите собрать проект самостоятельно:

### Требования
- 64-битная **Windows 10 / 11**
- Установленный **[Rust](https://rustup.rs/)** (инструментарий `stable-x86_64-pc-windows-msvc`)
- **Windows SDK** (компилятор ресурсов `rc.exe`, входит в состав Visual Studio Build Tools)

### Команды
```cmd
git clone https://github.com/vladimir214sd/PhobosWG_Client.git
cd PhobosWG_Client

# Релизная компиляция с LTO и оптимизацией по размеру
cargo build --release
```

Готовый бинарник будет лежать в `target/release/phobos-companion.exe` (можно переименовать в `phobos-client.exe`).
