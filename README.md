# Phobos WireGuard Client for Windows

<p align="center">
  <b>Ультракомпактный (~1 МБ) нативный графический клиент для протокола Phobos WireGuard под Windows.</b>
</p>

---

## ? Особенности

- ?? **Экстремально малый размер (~1.07 МБ)**: Полный графический клиент со встроенным сетевым драйвером Wintun (~400 КБ) и криптографическим движком. Никаких тяжелых игровых движков (wgpu/vulkan/directx) — чистый Win32 API.
- ?? **Самостоятельный VPN-туннель**: Полноценная реализация туннелирования на базе oringtun (Cloudflare) и wintun. Официальный WireGuard не требуется.
- ? **Архитектура Zero-Process**: Никаких вызовов внешних утилит (oute.exe, 
etsh.exe). Маршруты, DNS, MTU и IP-адреса настраиваются напрямую через системные Win32 API (iphlpapi.dll) за микросекунды, исключая любые мерцания окон консоли.
- ?? **Поддержка маскировки Phobos**: Встроенное STUN-оборачивание/разворачивание пакетов и симметричное XOR/CRC8-обфусцирование трафика для обхода блокировок и DPI.
- ?? **Нативный интерфейс в стиле WireGuard**: Двухколоночный интерфейс со списком туннелей, цветными индикаторами статуса, детальной карточкой пира, графиком скорости в реальном времени и журналом событий.
- ?? **Поддержка Drag & Drop**: Добавление туннелей простым перетаскиванием архива .tar.gz или .conf в окно программы.
- ?? **Автономность**: Драйвер wintun.dll вшит в бинарник и при необходимости автоматически извлекается в память/диск.

## ?? Быстрый старт

### Скачивание готового файла
1. Скачайте phobos-client.exe из раздела [Releases](https://github.com/).
2. Запустите программу и подтвердите запрос прав администратора (необходимо для сетевого адаптера Wintun).
3. Перетащите в окно архив конфигурации .tar.gz (или нажмите **«? Добавить»**).
4. Нажмите **«Подключить»**.

---

## ?? Сборка из исходников

### Требования
- **ОС**: Windows 10 / 11 (x64)
- **Rust**: 1.75+ (stable-x86_64-pc-windows-msvc)
- **Windows SDK**: установленный c.exe (для компиляции иконки приложения)

### Команды для сборки
`cmd
# Клонирование репозитория
git clone <URL_РЕПОЗИТОРИЯ>
cd PhobosWG_Client

# Сборка оптимизированного релизного бинарника
cargo build --release
`

Готовый файл будет находиться по пути:
	arget/release/phobos-companion.exe (переименуйте в phobos-client.exe).
